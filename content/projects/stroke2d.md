# Stroke2D — Histology & MRI Neuroimaging Platform

> **Sudha Gopalakrishnan Brain Centre (SGBC), IIT Madras**  
> **Platform Integration**: OpenAtlas Editor Platform

## Overview
At the Sudha Gopalakrishnan Brain Centre, researchers investigate ischemic stroke pathology by analyzing human brain tissue at microscopic and whole-organ scales. Correlating high-resolution post-mortem histology tissue sections with pre-mortem MRI scans is critical for understanding cellular damage and tissue recovery.

## The Challenge
Neuroscientists required an intuitive, zero-latency tool capable of handling ultra-large resolution histology imagery alongside 3D MRI cross-sections, allowing fine-grained spatial registration, rigid/affine coordinate alignment, and precise anatomical stroke boundary annotations.

## Implementation & Contribution
- **Stroke2D Interactive Visualizer**: Engineered an interactive browser module in Vanilla JavaScript and HTML5 Canvas to load, pan, zoom, and cross-reference histological slices with corresponding MRI planes.
- **Image Alignment & Registration Workflows**: Built algorithms and visual handles for scientists to manually and semi-automatically align anatomical landmarks between staining modalities.
- **Stroke Lesion Annotation**: Designed vector annotation tools enabling researchers to demarcate infarcted regions, compute area/volume metrics, and save vector boundary masks directly to PostgreSQL.
- **OpenAtlas Platform Modernization**: Contributed full-stack feature enhancements, REST API endpoints in Django, and UI components in Angular for the centre's flagship OpenAtlas Editor platform.

## Tech Stack
- **Frontend**: Vanilla JavaScript (Canvas & DOM manipulation), Angular, HTML5, CSS3
- **Backend & APIs**: Django, Django REST Framework, Python
- **Database**: PostgreSQL
- **Workflow**: Agile, Git code reviews, scientific data validation
